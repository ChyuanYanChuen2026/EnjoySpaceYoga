# 老師加開課、超收申請與管理員審核

對應原訂 9/30 的 MVC 功能。老師可申請、查看自己的紀錄；管理員可代填及審核所有申請。

## 管理員操作

1. 在原本啟動網站的終端機按 Ctrl+C，於 EnjoySpace.Web 目錄執行 `dotnet run --launch-profile http`，再登入管理員。
2. 點左側「老師加開／超收申請」，或開啟 `/TeacherRequests`。
3. 點「申請加開課」，選代辦老師並按「載入課程」，填課程、教室、起訖時間、新課堂總名額及原因，送出後應顯示「待審核」。
4. 開啟申請詳細頁，核對內容並勾選確認，按「核准」。預期只新增一堂場次，詳細頁標示「額外加開單堂」，原期課堂數、價格與固定班名單不變。
5. 點「申請超收」，選老師並載入課程，再選其尚未開始的授課場次，輸入新的**總名額**，例如原 10 人增為 12 人，填 12。
6. 核准超收後點「查看課堂與名額」。預期正常名額仍為原值，超收核准上限及目前名額上限更新為 12。
7. 另送一筆申請，審核時填原因並按「退回」。預期保留申請與審核紀錄，不新增課堂、不改名額。

若課程清單為空，確認老師為該課程的預設老師，且課程已啟用、學期已完成課表確認，狀態為開放報名或停止報名。

## 老師操作與帳號

已有可登入的老師帳號，可從 `/Account/Login` 登入，預設進入 `/TeacherRequests`。每次請求都重新核對帳號、角色及老師啟用狀態；老師只能選自己授課資源、查看自己的紀錄，不能使用管理員審核端點。

現有「老師管理」新增的是老師資料及尚未開放登入的帳號；本輪沒有替既有帳號重設密碼或自動啟用。尚無可登入老師帳號時，可以直接由管理員代辦完成上述驗收，代辦人編號會保留。老師 MVC 入口不等同後續 Vue 老師前台與 JWT 流程已完成。

## 使用者已確認的規則

- 加開課是同一期額外單堂，不改整期價格／堂數、不自動加入原固定班學生。加開課僅限該課程預設授課老師。
- 加開時段必須在學期內、尚未開始、結束晚於開始。送出與核准都檢查老師及教室是否與既有課堂重疊；首尾相接可接受。
- 超收只調整指定授課場次的上限，申請總名額必須大於目前上限，不提高整期招生上限，也不直接替任何學生取得名額。
- 核准後的加開場次會出現在場次管理與行事曆；符合原補課規則者可另外申請補課。自由堂課預約／扣堂仍屬後續項目。
- 待審申請不改課表或名額。同一課堂只允許一筆待審超收；同老師或教室的重疊待審加開申請會被拒絕。
- 同一份表單重送只建立一筆申請；核准、建立場次／調整名額與審核紀錄在同一筆交易完成。
- 審核需核對確認；退回必須填原因。超收目標課堂的資料版本若已改變，需退回並重新申請。老師、課程、學期及時段在核准時重新檢查。
- 已核准紀錄不提供直接刪除或撤銷；課堂取消／調課仍依後續排程開發。
